Arányos szolgálati idő kalkulátor

Bemeneti adatok
Minimálbér harmincada: - Ft

Átfedő jogviszonyok matematikai levezetése

1. eset – Teljes szolgálati időt eredményező jogviszony teljes átfedéssel

A – Megnevezés és levezetés B – Példa C – Általános képlet
Teljes beszámítás történik, nincs arányosítás.

szolgálati idő (S) = naptári napok száma (N) 		N = 200 nap
S = 200 nap 		S = N

Értelmezés:
S = figyelembe vehető szolgálati idő (nap)
N = vizsgált időszak naptári napjainak száma
Ebben az esetben a szolgálati idő mindig pontosan megegyezik a tényleges napok számával, függetlenül attól, hogy az 100, 365 vagy 1200 nap.


2. eset – Részleges átfedés teljes szolgálati időt eredményező jogviszonnyal

A – Megnevezés és levezetés B – Példa (2003) C – Általános képlet
arányszám (r) = járulékalapot képező jövedelem (J) / azonos időszak minimálbére (M)

szolgálati idő (S) = arányszám (r) × napok száma (N) 		J = 312 000 Ft
M = 600 000 Ft
r = 312 000 / 600 000 = 0,52
N = 250 nap
S = 0,52 × 250 = 130 nap 		r = J / M
S = (J / M) × N

Értelmezés:
S = figyelembe vehető szolgálati idő (nap)
r = foglalkoztatási arányszám
J = az arányosítandó időszak járulékalapot képező jövedelme
M = azonos időszakra számított minimálbér
N = arányosítandó időszak napjainak száma


3. eset – Két arányosítandó jogviszony teljes átfedéssel

A – Megnevezés és levezetés B – Példa C – Általános képlet
összes jövedelem (Jössz) = első jogviszony jövedelme (J₁) + második jogviszony jövedelme (J₂)

arányszám (r) = összes jövedelem (Jössz) / minimálbér (M)

szolgálati idő (S) = arányszám (r) × napok száma (N) 		J₁ = 200 000 Ft
J₂ = 250 000 Ft
Jössz = 450 000 Ft
M = 600 000 Ft
r = 0,75
S = 0,75 × N 		Jössz = J₁ + J₂
r = (J₁ + J₂) / M
S = ((J₁ + J₂) / M) × N

Értelmezés:
S = figyelembe vehető szolgálati idő (nap)
J₁, J₂ = párhuzamos jogviszonyok jövedelmei
Jössz = összevont jövedelem
M = adott időszak minimálbére
N = időszak napjainak száma


4. eset – Részleges átfedés, szüneteléssel

A – Megnevezés és levezetés B – Példa C – Általános képlet
nettó napok (N') = teljes napok (N) − szüneteléssel érintett napok (K)

összes jövedelem (Jössz) = J₁ + J₂

arányszám (r) = összes jövedelem (Jössz) / időarányos minimálbér (M')

szolgálati idő (S) = (arányszám (r) × nettó napok (N')) + szünetelt napok (K) 		N = 200 nap
K = 20 nap
N' = 180 nap
Jössz = J₁ + J₂ 		N' = N − K
Jössz = J₁ + J₂
r = Jössz / M'
S = (Jössz / M') × (N − K) + K

Értelmezés:
S = figyelembe vehető szolgálati idő (nap)
N = teljes vizsgált napok száma
K = szüneteléssel vagy járulékköteles jövedelem nélküli napok száma
N' = ténylegesen arányosítandó napok száma
J₁, J₂ = jogviszonyok jövedelmei
Jössz = összevont jövedelem
M' = adott időszakra számított minimálbér

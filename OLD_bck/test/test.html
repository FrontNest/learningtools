Szuper döntés 👍 az OSM tényleg passzol a HUD appodhoz. Menjünk **konkrétan, lépésről lépésre**, hogy *ne kelljen órákat fórumokon túrnod* 🙂 --- ## 🗺️ 1️⃣ Honnan lehet letölteni az OpenStreetMap adatokat? ### 🔹 **Geofabrik – a legjobb kiindulópont (ajánlott)** 👉 [https://download.geofabrik.de](https://download.geofabrik.de) **Miért ez a legjobb?** * országokra bontott * friss (naponta frissül) * stabil * pont azt adja, amire szükséged van 📍 **Magyarország adatfájl:** ``` hungary-latest.osm.pbf ``` Ez tartalmaz: * az összes utat (`highway`) * a `maxspeed` tageket * településhatárokat, övezeteket stb. 📦 Méret: ➡️ kb. **120–150 MB** (PBF tömörítés) --- ## 🧩 2️⃣ Milyen formátumban? ### ✅ **.osm.pbf** (ajánlott) * bináris, tömörített * gyors feldolgozás * minden komoly OSM tool ezt használja ❌ `.osm.xml` → nagy és lassú ❌ online tile API → nem erre való --- ## ⚙️ 3️⃣ Mit csinálsz vele technikailag? ### Tipikus pipeline (HUD apphoz ideális): ``` OSM PBF fájl ↓ Előfeldolgozás (PC / szerver) ↓ Útszakasz + maxspeed kivonat ↓ Optimalizált adatfájl (pl. SQLite / FlatBuffers) ↓ Mobil app (offline) ``` 👉 **nem** az appban parsolod a PBF-et, hanem **előre**. --- ## 🛠️ 4️⃣ Feldolgozó eszközök (konkrét ajánlás) ### 🔹 **osmium-tool** (CLI, brutál gyors) 👉 [https://osmcode.org/osmium-tool/](https://osmcode.org/osmium-tool/) Példa: csak az utak és sebességek kivágása: ```bash osmium tags-filter hungary-latest.osm.pbf \ w/highway \ -o roads.osm.pbf ``` ### 🔹 **Osmosis** (régebbi, de használható) * Java alapú * kicsit lassabb ### 🔹 **GraphHopper** (ha routing is lesz) * eleve feldolgozza a maxspeed-et * Androidon is működik * offline ready --- ## 🚦 5️⃣ Hogyan nyered ki a sebességhatárt? OSM út (way) példa: ```text highway=primary maxspeed=90 ``` Speciális esetek: ```text maxspeed=50 maxspeed:conditional=30 @ (school_hours) zone:maxspeed=hu:urban ``` 👉 A logikád kb.: 1. `maxspeed` 2. `maxspeed:conditional` (ha értelmezed) 3. `zone:maxspeed` 4. fallback magyar KRESZ szerint --- ## 🇭🇺 6️⃣ Magyarország-specifikus fallback (fontos!) Ha **nincs maxspeed**: ```text motorway → 130 trunk → 110 primary/secondary → 90 residential → 50 living_street → 20 ``` Ezt **te kódolod**, nem az OSM. --- ## 📱 7️⃣ Mobilos használat – hogyan? ### Két bevált irány: ### 🅰️ Teljesen offline * SQLite / Realm / saját bináris formátum * GPS → nearest road segment * sebességhatár azonnal ### 🅱️ Fél-online (ritkán frissít) * havi 1 adatfrissítés * háttérben letölt * új OSM snapshot 💡 HUD appnál az **A verzió** a király. --- ## ⚖️ 8️⃣ Licenc – mit NE felejts el!
